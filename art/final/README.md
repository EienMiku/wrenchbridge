# 当前通用扳手材质

`universal-wrench.png` 为用户绘制、共同微调后确认的原生 16×16 版本。采用用户修改的 soft 稿，再将内角 `(10, 5)`（从左上角起、下标从 0 开始）压暗为 `#808283`。

运行时使用同一 PNG：`common/src/main/resources/assets/wrenchbridge/textures/item/universal_wrench.png`。工作稿及此前预览保存在 `art/user-refinement/`，早期稿保存在 `art/handdrawn16/` 和 `art/texture-refresh/`。

后续修改以用户确认的 PNG 为准。早期重建脚本和像素网格只对应各自历史稿，不应覆盖当前材质。
