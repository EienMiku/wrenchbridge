# 0.1.0-alpha.7：默认拆卸、原生功能与 AE2 网络信息

本次改动面向 Minecraft 1.21.1 / NeoForge。

默认“通用（拆卸）”此前一直暴露普通扳手标签与旋转能力，Mekanism 等模组会把普通右键也当作扳手操作。现在只在默认模式的潜行使用期间提供这些原生能力，普通右键保留方块原来的交互，例如打开机器界面。标签的物品栈查询、列表查询及 Item Holder 查询遵循相同范围；回调结束或异常时立即恢复。

按模式区分行为：

- **通用（拆卸）**：潜行右键进入共享拆卸；普通右键不以扳手身份旋转或配置机器。
- **模拟配置工具（扳手）**：保留原工具的跨模组功能，包括普通右键旋转 Create 传动杆。对 Create 调用与原生扳手相同的 `IWrenchable.onWrenched`，不换装，也不重放第二次点击。
- **模拟旋转、配置等模式**：按明确选择的原生模式执行，来源工具的实际数据和消耗规则继续有效。
- **原模组的真实工具**：保留原生操作，不受本次默认通用模式限制。

默认潜行使用在完整的客户端/服务端原生交互流程中提供临时标签，因此只认通用标签、尚未被 `Targets` 列出的原生事件也仍能处理该次操作。没有增加通用破坏方块兜底。主副手继续遵循游戏的优先级，保护拒绝与回调异常不触发第二套策略。

模拟 AE2 网络工具此前固定打开卡片收纳页，丢失了点击的网络目标。现在调用 AE2 原工具的入口，由原模组选择网络统计页或收纳页，并保留其部件选择、权限检查和目标特殊交互。原生菜单定位器仅在本次调用内改用真实网络工具的物品栏槽位，点击位置仍通过 AE2 原包同步；手中的通用扳手不替换。网络信息页能读取连接设备和耗能等实时数据；对空气或普通方块使用仍打开卡片收纳页。界面绑定真实来源，移走来源工具后遵循 AE2 原生失效规则。便携 GUI 仍要求来源位于普通玩家物品栏或副手，暂不支持只放在背包内部的来源。

本轮服务端验证包括：主副手默认普通使用均不旋转 Mekanism 与 Create 方块；明确选择 ROTATE 仍能旋转；配置工具 WRENCH 模式旋转传动杆与原工具结果一致；来源配置模式保留；潜行拆卸、保护拒绝、未知目标原生事件及异常后的上下文清理。之前的 395 个副手组合、70 个集成动力机器用例、背包与消耗检查一并回归。

独立客户端的 14 个场景全部通过，包含真实交互包的两项检查：默认普通右键打开 Mekanism 机器界面且方块朝向不变；默认潜行右键收取机器。客户端预测与服务端处理结束后均清除临时能力，通用扳手保持原物品。原有主副手配置叠层、背包来源、缺失来源及材料混用配方也通过验证。

新增的 AE2 客户端检查对照了原版网络工具、主手模拟和副手模拟，均打开网络统计页，服务端绑定包含 2 个节点的实际网络，客户端收到 2 组设备统计；主副手模拟后都保留原来的通用扳手和来源工具。对空气及非网络方块使用时均打开收纳页。服务端另验证主副手定位、AE2 原包编解码、来源离开后界面失效，以及作用范围清理。结果见 `alpha7-client-verification-result.txt`、`client-render-verification.json`、`shared-intent-verification.json` 和 `ae2-network-menu-verification.json`，实际截图在 `alpha7-interaction-check/`。

配方、材质、G 菜单、Mekanism 原生叠层及 6 GiB 测试实例内存设置沿用 alpha.6。更新已有实例只替换本模组 JAR，保留存档与按键；游戏仍在运行时可退出后使用随包的更新脚本。
