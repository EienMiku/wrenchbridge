# 本地 PCL 内存配置修正与旋转排查

2026-10-24 的扩充版本地安装脚本把 PCL 的 `VersionRamCustom` 写成了 60，并错误地将其解释为 6 GiB。该字段实际是非线性滑块刻度：60 对应 70 GiB；21 才对应 6 GiB。此错误来自本项目的本地安装脚本。

用户此次 JVM 故障记录显示最大堆参数为 `-Xmx71680m`，JIT 编译线程申请约 2.8 MiB 本机内存失败；故障时系统可提交内存仅余约 15 MiB。这能确认本次 Java 退出及严重系统内存压力，不能单凭该记录判定为旋转递归。

已将扩充版本地刻度修正为 21（6 GiB），两个先前由项目创建的测试版本从错误刻度 50 修正为 19（5 GiB），并修正安装脚本。只改本地实例的内存项，保留备份，未修改全局启动器设置。PCL 如果正在运行，应重新打开以读取新配置，再确认版本设置显示 6 GiB。

对照依据：[PCL 的实例内存计算源码](https://github.com/Meloong-Git/PCL/blob/main/Plain%20Craft%20Launcher%202/Pages/PageInstance/PageInstanceSetup.xaml.vb)。

通用扳手的默认“通用（拆卸）”没有普通右键旋转原版带釉陶瓦的动作。旋转该方块需要使用补充包原扳手，或携带该扳手后，在 G 菜单中选择对应模拟功能。为该场景增加了原扳手、默认通用模式、模拟模式及真实耐久的对照测试；隔离验证进程限制为最大 2 GiB。

Pipez 的潜行右键原生用于调整抽取和连接，不提供右键收回整根管道的动作；共享拆卸保持此语义。其扳手仍可共享拆卸其他已有原生收取入口的模组设备。参考 [Pipez 原生说明](https://github.com/henkelmax/pipez#configuring-pipes)。

对照测试通过：补充包原扳手可旋转白色带釉陶瓦；默认通用模式不改变朝向；模拟补充包扳手能够旋转，并对真实来源工具扣除 1 点耐久、保持主手和来源槽位不变。
