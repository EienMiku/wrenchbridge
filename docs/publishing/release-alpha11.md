Wrench Bridge alpha.11 adds a **Sharing settings** page on all six supported platforms. **Other wrenches** sharing is enabled by default and can be toggled from the mod-list configuration page or the bottom of the G palette. The choice is saved locally and synchronized independently for each player.

Turning it off disables Wrench Bridge's extra shared dismantling for other mods' tools. Native compatibility, the universal wrench and simulated modes remain available.

Choose the JAR for your exact game version and loader, and update both client and server. Forge 1.12.2 additionally requires **MixinBooter 11.18+**. Older preview files remain available in the previous release.

All six builds passed dedicated-server checks for the new setting and existing interactions. The 1.21.1 client also passed UI, real network synchronization and saved-preference checks across two launches. [Verification details](https://github.com/EienMiku/wrenchbridge/blob/main/docs/alpha11-sharing-toggle.md).

六个平台新增默认开启的「其他扳手互通」客户端开关，可从模组配置页或 G 菜单底部的「互通设置」中修改，按玩家保存并自动同步。关闭仅影响本模组为其它扳手额外提供的共享拆卸，原生兼容、通用扳手和模拟模式继续有效。客户端和服务端需一起更新。
