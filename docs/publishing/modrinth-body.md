# Wrench Bridge

Wrench Bridge adds a universal wrench and lets compatible wrench-like tools from different mods share their dismantling abilities.

## What it does

- Sneak and use a supported block to dismantle it. The universal wrench's shared dismantling mode does not require carrying another tool.
- Press the configurable **G** key to select a carried native tool or one of its supported modes.
- Keep the universal wrench in your hand. The actual source tool supplies its data, energy, air, and durability.
- Use supported carried containers, including Sophisticated Backpacks, as tool sources.
- Use either hand, with the normal priority for meaningful main-hand actions.

The default shared mode preserves ordinary block interactions, such as opening a machine. Explicit native modes retain their intended rotation and configuration behavior. Ordinary right-click does not open the mode menu.

Craft the wrench with two ingots and two rods; mixed materials are allowed:

```text
 I 
 SI
S  
```

`I` is any ingot; `S` is any rod or stick.

## Installation and compatibility

Choose a file for your Minecraft version and loader from the **Versions** tab, and install any dependencies listed there. Install the same build on client and server; single-player needs only the client installation.

Integrations include AE2, Mekanism, Create, AnvilCraft, PneumaticCraft and more. These tool mods are optional; available functions follow the installed mods and their native tool behavior.

## 简体中文

为不同模组的扳手类工具共享拆卸能力，并添加一把可以模拟原工具功能的通用扳手。

- **潜行右键**：共享拆卸。通用拆卸不要求携带其它工具。
- **G 键**：打开模式菜单，可在控制设置中改键。普通右键不会打开模式菜单。
- **模拟模式**：借用随身真实工具的功能、电量、气压和耐久；通用扳手始终留在手中，原工具保留自己的设置。
- 支持主副手，以及精妙背包等可识别的随身容器。

配方如上：`I` 为任意锭，`S` 为任意棍，允许混用材料。

请在「版本」页选择适合自己 Minecraft 版本与加载器的文件，并安装该文件列出的依赖。客户端与服务端安装同一构建，单机只需安装在客户端。各第三方工具模组均为可选兼容对象，具体功能遵循原工具的行为。

作者与原始材质：EienMiku。开发过程使用了 AI 辅助。
