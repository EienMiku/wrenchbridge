# 0.1.0-alpha.2：通用扳手模拟模式

本次行为更新先支持 Minecraft 1.21.1 / NeoForge。其余五个平台保留 alpha.1，尚未移植此模拟机制。

- G 菜单仅在主手持通用扳手时打开。模式保存在这把通用扳手自己的数据中，各个来源工具的模式分别记忆。
- 选择模式不会交换物品栏、取出背包工具、改物品注册 ID、创建可领取的原生工具或修改原工具选定的模式。
- 使用模拟功能时，主手仍保持原来同一份通用扳手。原生回调收到受控的工具上下文；不通过给玩家换装实现。
- 按之前选定的规则，随身的真实原工具提供能力、能量和耐久。原生动作产生的持久数据遵循原模组 API；临时借用的工作模式在动作结束后恢复。
- 精妙背包等通过公开物品栏能力访问：一次动作内取用并归还原槽位，不要求玩家预留空格。未携带来源工具时停止模拟；通用共享拆卸仍无需来源工具。
- 其他模组的真实扳手只共享拆卸范围，保留原有身份和原生切换操作；它们不能通过本模组菜单相互转换。

目前验证：原有 20 组代表性跨模组拆卸及保护拒绝；四种原工具 × 四种靶机的 16 组通用扳手模拟；Mekanism 配置、扳手与旋转；物品栏位置、回调中的主手身份、原模式恢复、真实耐久消耗、满物品栏及缺失来源工具。

铁砧锤便携铁砧与 AE2 网络工具菜单使用专门的原生菜单来源定位。对应原工具需放在玩家普通物品栏中；嵌套容器里的这两种原生菜单暂不支持。其他模组特有的按键和自定义网络功能仍需专门适配，不能仅靠识别一个 Item ID 完整模拟。

技术上对标准扳手标签提供按 ItemStack 的动态视图，并在受控拆卸调用中补充临时扳手能力。静态注册表标签不再令处于配置模式的通用扳手被第三方模组误判为拆卸工具。调用结束立即撤销上下文，原生工具和物品栏均保持其身份。

后续材质采用用户绘制并确认的 16×16 钢制扳手，见 `art/final/`。材质调整不改变模拟行为。
