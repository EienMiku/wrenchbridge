# 0.1.0-alpha.3：自适应菜单与精简文案

本次界面更新支持 Minecraft 1.21.1 / NeoForge，沿用 alpha.2 的通用扳手模拟机制。其余五个平台保留 alpha.1 的交互机制；共同材质更新为用户确认的 16×16 图。

- 列表行数由 Minecraft 缩放后的窗口高度决定，取消每页最多 7 行的限制。翻页和“完成”固定在窗口底部，保留 12 个 GUI 像素的底边距。
- 在 854×480 的 GUI 视口下可显示 14 行；320×240 下显示 4 行。窗口缩放后保留搜索内容及原先浏览的条目所在页。
- 列表使用“通用（拆卸）”“配置工具（物品配置）”这类简短名称。模拟说明、模式记忆规则和容器来源放在悬停提示中；对应的英文同步更新。
- 原生工具名沿用其本身的翻译与样式。物品提示中选中的工具及模式也改为本地化名称。
- 子模式优先读取原模组枚举提供的翻译组件或翻译键，保留参数及样式；本模组的译名只作兜底。切换提示和物品提示使用同一套名称。
- 扳手模式菜单仅通过可配置的快捷键打开（默认 G），取消普通对空气使用打开菜单。选中模式本身的原生交互继续正常工作。
- 修复重复渲染背景导致标题和说明文字被模糊的问题。翻页按钮在第一页／最后一页禁用，空搜索显示提示。
- 材质采用用户确认的 soft 内角调整版，见 `art/final/`。

界面布局验证覆盖多组缩放视口，检查行数利用、底部边界与控件不重叠。拆卸、模拟动作与消耗协议未改动；原先实际模组的验证记录见 `alpha2-simulation.md` 和 `verification.md`。

本轮隔离服务端回归通过：原有 20 组真实工具拆卸、16 组通用扳手模拟及精妙背包检查；新增检查确认普通对空气使用返回 PASS、Mekanism 模式翻译组件及其参数得以保留、显示模式名称不会修改原工具的状态。客户端布局由边界测试验证，未在用户正在运行的客户端中热替换代码。
