# 0.1.0-alpha.8：直接使用背包里的 AE2 网络工具

Minecraft 1.21.1 / NeoForge。AE2 网络工具可以留在精妙背包等可识别的随身容器中，选择其模拟模式后直接打开网络统计页或卡片收纳页，无需手动移到玩家物品栏，也无需留空格。主手和副手使用同一流程，通用扳手保持原物品。

网络工具平时仍在容器原槽位。原生菜单的点击、快捷移动及原生操作入口通过容器能力短暂取出真实工具，完成后把修改保存回原槽位；显示与有效性检查不持续取出工具，也不直接修改 `IItemHandler.getStackInSlot` 返回的物品。客户端接收用于原生界面显示的快照，服务端只接受已绑定玩家当前随身来源，客户端快照不会成为真实工具。没有新增 AE2 或背包的硬依赖，AE2 存在时注册其菜单定位协议的可选实现。

菜单绑定本次选中的容器和内部槽位，不会在来源消失时悄悄切换到另一把同类工具。移走背包或工具会使界面失效；拒绝提取时不执行原生写入；原槽位不能归还时保留真实工具到玩家物品栏，满时掉落。原生回调异常也执行归还。菜单关闭、来源失效和玩家离线时清理绑定。工具不会长时间从容器取走，也不会保存在临时服务端副本中等待关闭。

本轮独立客户端的 19 个场景通过，包含精妙背包中网络工具的主副手模拟、全满的玩家物品栏、实际网络统计、原生卡片点击包的取出与放回持久化，以及移走背包后的界面关闭。服务端的 5 项容器菜单检查另验证原生收纳槽写入、回调异常归还、拒绝提取、拒绝归还及归还异常时的工具数量守恒；原有拆卸、保护、消耗、副手和模式隔离用例一起回归。具体结果见 `container-menu-verification.json`、`client-render-verification.json`、`alpha8-verification-result.txt` 和 `alpha8-client-verification-result.txt`。实际截图在 `alpha8-container-menu-check/`。

仍沿用一层随身容器探测范围及公开能力规则，不访问远程箱子。精妙背包已实际验证，其他容器是否允许取用由其能力实现决定。铁砧锤的便携铁砧界面仍需要普通玩家物品栏中的真实铁砧锤；本次扩展针对 AE2 网络工具。

客户端与服务端均需更新到 alpha.8；网络协议标识已更新，避免较早客户端收到其不认识的容器菜单定位器。配方、材质、G 菜单、共享拆卸与明确选择的原生旋转行为沿用 alpha.7。只更新现有实例的模组 JAR，保留存档、按键及启动器内存设置。
